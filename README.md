# Rock Paper Scissors Game 🎮

A simple **Rock Paper Scissors game** made using **HTML, CSS and JavaScript**.

I originally created this game using Python in the terminal. Later, I converted it into a web-based game to practice frontend development and JavaScript.

## 🚀 Features

* Player can choose Rock, Paper or Scissors
* Computer makes a random choice
* Displays player and computer choices
* Keeps track of:

  * Wins
  * Losses
  * Ties
* Reset game option
* Simple and responsive user interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Python (original version)

## 🎮 How to Play

1. Open `index.html` in a web browser.
2. Choose one of the three options:

   * Rock 🪨
   * Paper 📄
   * Scissors ✂️
3. The computer will randomly select an option.
4. The game will decide whether you win, lose or tie.
5. Use the **Reset Game** button to start the score again.

## 🧠 Game Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Same choices result in a tie
